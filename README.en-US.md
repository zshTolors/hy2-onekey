# 🌀 hy2-onekey

> **Hysteria2 One-Click Deployment Script**  
> Automatically deploy Hysteria2 server and generate ready-to-use Clash subscription configuration  
> One-click setup your own VPN / Clash subscription link  
> Supports Ubuntu / Debian / CentOS / Rocky / AlmaLinux  
> **Does not disrupt existing Nginx environment**

---

## ✨ Project Introduction

`hy2-onekey` is a **secure, reusable, and minimally invasive** Hysteria2 one-click installation script, aiming to:

- Allow ordinary users to **understand complex configurations without needing to**
- Ensure existing servers **will not be "polluted" or damaged by the script**
- Automatically generate **Clash / Clash Meta / Stash directly usable subscription configurations**

---

## 🚀 Features

- ✅ One-click installation of Hysteria2 server
- ✅ Automatic application of Let's Encrypt TLS certificates
- ✅ Automatic handling of certificate permissions
- ✅ Automatic opening of UDP ports
- ✅ Automatic registration and startup of systemd services
- ✅ Automatic generation of Clash complete configuration (rule mode)
- ✅ Automatic generation of subscribable YAML files
- ✅ **Does not overwrite or modify existing Nginx configurations**
- ✅ Supports `curl | bash` interactive execution

## 🌐 Preparations Before Use (Very Important)

Before running the script, you **must have your own domain name** and complete domain resolution.

### 1️⃣ Prepare Domain Name

- Any domain you can control is acceptable

### 2️⃣ Configure DNS Resolution

In your domain's DNS management panel, add an **A record**:

| Type | Hostname | Points To |
| ---- | -------- | --------- |
| A    | v.example.com | Your server public IP |

> ⚠️ Domain must **be resolved to server IP in advance**  
> Otherwise, Let's Encrypt certificate application will fail.

You can verify if the resolution is effective on your server:
```bash
ping v.example.com
```

## 📦 Installation and Usage (One-Liner)

```bash
curl -fsSL https://raw.githubusercontent.com/zshTolors/hy2-onekey/main/install-hy2.sh | bash
```

Or:

```bash
wget https://raw.githubusercontent.com/zshTolors/hy2-onekey/main/install-hy2.sh
chmod +x install-hy2.sh
./install-hy2.sh
```

---

## 🧭 Installation Process Explanation

The script guides you through entering:

- 📍 Domain (must be resolved to current server IP)
- 🔢 UDP listening port (recommended 20000–40000)
- 🔐 Connection password

The script will automatically complete:

1. System dependency installation
2. TLS certificate application (standalone mode)
3. Hysteria2 installation and configuration
4. UDP port opening
5. systemd service startup
6. Clash configuration generation
7. Subscription file publishing (HTTP)

---

## 📄 After Installation

- Clash configuration file: `/root/hy2/clash.yaml`
- Subscription address: `http://<serverIP>/clash/clash.yaml`

## ❓ Frequently Asked Questions (FAQ)

### Q1: Client reports `unsupported proxy type: hysteria2`

This is caused by the client not supporting the Hysteria2 protocol.

Please use:

- [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev)

- [FLClash](https://github.com/chen08209/FlClash)

### Q2: Why not provide subscriptions via HTTPS?

This is an **intentional security design**:

- Does not overwrite your existing HTTPS site
- Does not automatically inject Nginx configuration
- Does not create "black box behavior"

If you need HTTPS subscriptions, please **manually configure Nginx**.

### Q3: Will the script damage my existing Nginx?

**No.**

- Does not modify server blocks
- Does not overwrite configuration files
- Only places a static YAML file

## 🧹 Uninstallation Instructions

If you need to completely remove the Hysteria2 deployed by this project, you can use the uninstallation script:

```bash
curl -fsSL https://raw.githubusercontent.com/zshTolors/hy2-onekey/main/uninstall-hy2.sh | bash
```

Or:

```bash
wget https://raw.githubusercontent.com/zshTolors/hy2-onekey/main/uninstall-hy2.sh
chmod +x uninstall-hy2.sh
./uninstall-hy2.sh
```

### Uninstallation Script Instructions

- The uninstallation script **only removes content created by this project**:

- Hysteria2 program
- systemd services
- `/etc/hysteria` configuration directory
- `/root/hy2` Clash configuration
- Subscription files generated by this project

Will not delete:

- Nginx
- Let's Encrypt certificates
- Certbot
- User's existing sites or configurations
- If you need to delete firewall rules, please handle them manually.
